Export / backup

Copy the Markdown into your Design Shark repository. The JSON backup holds all progress, notes and links.

 Install on your phone
  • iPhone (Safari): Share → Add to Home Screen.
  • Android (Chrome): ⋮ menu → Install app / Add to Home screen.
  • Desktop (Chrome/Edge): install icon in the address bar.

Full offline install needs the file hosted with manifest.webmanifest, sw.js and the icons next to it (included in your download). Your notes stay in this browser; use Export → JSON to move them.
